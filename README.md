# Reanimated School

A React Native app built with Expo that teaches React Native Reanimated through interactive lessons and animations.

## Prerequisites

- [Bun](https://bun.sh/) (v1 or later)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- iOS Simulator (Mac only) or Android Emulator, or a physical device with [Expo Go](https://expo.dev/go)

## Getting Started

### Install dependencies

```bash
bun install
```

### Run the app

```bash
# Start the Expo dev server
bunx expo start

# Or run directly on a specific platform
bunx expo start --ios
bunx expo start --android
bunx expo start --web
```

Once the dev server is running, press `i` for iOS simulator, `a` for Android emulator, or scan the QR code with Expo Go on your device.
